# License expired

## Problem

The customer license is expired and the database cannot be started.

## Procedure

1. Confirm the expiration state and impacted database.
1. Generate or obtain a temporary extension license (typically 2 weeks, per internal policy).
1. Deliver the license to the customer, or upload/apply it directly when allowed.
1. Start the database and verify service availability.
1. Inform the account manager about the incident and temporary extension usage.

## Customer Communication

Include the following in your response:

- Confirmation that license expiry caused the outage/startup block.
- Temporary mitigation applied.
- Required follow-up for permanent license update.

## Result

The incident is resolved when the valid license is applied and the database starts successfully.

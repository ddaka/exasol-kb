# Unica connection with MS SQL template

## Purpose

Unica may generate SQL Server-style SQL that Exasol does not support directly (for example `GETDATE()` and `SELECT ... INTO ...`).

Use an SQL preprocessor script to rewrite statements at session runtime.

## Typical symptoms

- `Feature not supported: select target list`
- `object GETDATE not found`

## Step 1: Create rewrite script

```lua
OPEN SCHEMA xxxxx;

CREATE OR REPLACE SCRIPT xxxxx.ppscript() AS

function unicaproc(sqltext)
    local tokens = sqlparsing.tokenize(sqltext)

    for i = 1, #tokens do
        if string.upper(tokens[i]) == 'GETDATE' then
            tokens[i] = 'CURRENT_DATE'
        end
    end

    if #tokens > 0 and string.upper(tokens[1]) == 'SELECT' then
        for i = 1, #tokens do
            if string.upper(tokens[i]) == 'INTO' then
                tokens[i] = 'INTO TABLE'
            end
        end
    end

    return table.concat(tokens)
end
/
```

## Step 2: Create preprocessor wrapper

```sql
CREATE OR REPLACE SCRIPT xxxxx.unicapp() AS
  IMPORT('xxxxxx.ppscript', 'ppscript')
  sqlparsing.setsqltext(ppscript.unicaproc(sqlparsing.getsqltext()))
/
```

## Step 3: Enable for session

```sql
ALTER SESSION SET sql_preprocessor_script = xxxxx.unicapp;
```

Disable if needed:

```sql
ALTER SESSION SET sql_preprocessor_script = '';
```

## Step 4: Validate

```sql
SELECT 'abc' AS "abc" INTO xxxxx.abc FROM dual;
SELECT COUNT(*) FROM xxxxx.abc;
SELECT * FROM xxxxx.abc;
```

## Notes

- Keep preprocessor scope limited to affected sessions/users.
- Validate rewriting rules against representative Unica workload.
- Extend rewrite rules for additional SQL Server-specific constructs as needed.

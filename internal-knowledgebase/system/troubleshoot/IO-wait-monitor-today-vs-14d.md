# IO wait monitor today vs 14d

## Problem

An alert was created as follows:

Case Subject: IO wait monitor today vs 14d
Case Description: At least 100% more IO WAIT: TODAY XX 14d: YY

## Procedure

Check the hardware of the cluster.
This could be caused by a faulty CPU or the CPU is at its maximum.

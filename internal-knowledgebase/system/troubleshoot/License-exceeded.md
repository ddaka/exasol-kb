# License exceeeded

## Problem

An alert was created as follows:

Case Subject: License exceeded

Case Description:

- License exceeded: Databases raw sizes of xx.xx GiB exceed license limit of xx.xx GiB (105.0 %). Databases no longer permit data insertion.
## Procedure

In this case, there is nothing we can do. We need just to inform the customer that the license is exceeded and that the Database no longer permit data insertion.

The customer should delete some data or increase the license.

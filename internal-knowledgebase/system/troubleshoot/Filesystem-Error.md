# Filesystem Error

## Problem

An alert was created as follows:

Case Subject: Filesystem Error
Case Description: Filesystem corrupt on nXXXX,platform=XXXX CLUSTER-XXX

## Procedure

Most likely there is a broken/faulty disk on this node. Check the hardware for the affected node and swap it with the reserve node as quickly as possible.

# Certificate expiry

## Problem

An alert was created as follows:

Case Subject:  Certificate expiry

Case Description: Certificate expiry

## Procedure

On Tags field, we can find Cluster ID, Account Group, Database Name.

This alerts shows us about the TLS certificate expiration.

Action:

1) Check the validity of the TLS certificate in EXAoperation URL
2) Inform the customer for the TLS certificate expiration time

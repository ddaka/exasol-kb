# Internal - spawning a terminal on IPMI SOL

## Overview

This article describes how to spawn a terminal on a license server if no direct access to the network interfaces is possible. To install one of those solutions you need access via KVM console (iDRAC, iLO, etc.) or physical access to the system.

## Regular terminal after the boot process

### Prerequisites

* you need to know which interface is used by IPMI SOL
* usually, this can be configured in the BIOS settings
* if possible: choose "ANSI" instead of "VT100" in those settings

### Step 1

create a file with the following content and save it under /etc/init/ttyS1

```
start on runlevel [345]
stop on runlevel [S016]

respawn
instance /dev/ttyS1
exec /sbin/agetty -8 ttyS1 115200 ansi
```

### Step 2

add your serial tty to /etc/securetty

```shell
echo "ttyS1" >> /etc/securetty
```
### Step 3

enable your new serial tty

```shell
cluster1 [root@n0010 ~]# start ttyS1
```
### Pre-boot terminal

Sometimes it's useful to have a terminal before the regular boot procedure starts. If you want to type in your LUKS password you have to define a serial console, which can be used as TTY. Just add on the kernel lines the parameter "console=ttyS1" like this

This is more simple then the first method and the console but you may encounter problems if you are using iDRAC KVM or HP ILO. And keep in mind that this method does not update safe: it's possible that those parameters will be overwritten on the next update.

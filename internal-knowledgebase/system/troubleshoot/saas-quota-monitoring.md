# SaaS - Quota Monitoring

## Overview

AWS services have service limits based on per region or per account. Though most of these service quota limits are allowed to be increased, there are some of them, which AWS will not allow you to be changed and they are called hard limits.

The metrics collected from the script help us send information to CloudWatch, and we monitor every infrastructure-related service in Datadog.

### Monitored Services

1. #### VPCs per Region
2. #### EC2 Elastic IPs
3. #### Gateway Endpoints
4. #### Interface Endpoints
5. #### Routes
6. #### Internet Gateways per Region
7. #### S3 Buckets
8. #### vCPU

Note:  We will receive an alarm if any of the Services listed above exceed the Warning Thresholds. The quota adjustment script will send a request to double the value of the existing quota. Even if a request is sent, it does not mean that the request has been accepted by AWS, so we need to check the status of the tickets generated by the script.

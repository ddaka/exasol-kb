# License creation for POC and testing only - not for productive usage

## Overview

This article explains how you can create a license and send it. This is only valid for non-productive licenses, reason is that productive licenses are created automatically by thd CPQ process and are bound to an entitlement.

## Explanation

In order to create a license go to account.

![Account screen](images/Account.png)

In the account, on the top right corner click on the drop down menu and then generate license.

![Account / Generate License](images/account_generate_license.png)

Now choose the license type, for systems before version 8 select **'License 7'**, for systems with and after version 8 select **'License 8'**.

![Choose License type](images/choose_type.PNG)

Now set the specifications for the license.

![Fill license properties](images/set_options.PNG)

Click on Next and then on **'Click here'** to get directly to your new license.

![Final license creation window](images/click_here.PNG)

You can now find the license in the tab **'Related'**, then **'Files'**.

![Asset / Related](images/related_files.PNG)

In case you need to send the license to someone, go to **'Details'** and add a **'License Recipient'**

![Details / License Recipient](images/lic_recipeient.PNG)

Afterwards, go to **'Activity'** and click on **'Send License'**.

![Activity / Send License](images/click_send.PNG)

Now insert the **'License Sharing'** template. For this click on **'Insert, create, or update tempalte'** in the bottom left.

![License Sharing template](images/insert_template.png)

In the search field type **'License'** and then on **'License Sharing'**.

![Particular template](images/choose_license_sharing.PNG)

Now attach the license to your mail. Click on **'Attach file'**.

![Attach file](images/attach_file.png)

Here wait a moment until files appear, then switch to **'Related Files'** and add the license.

![Related Files](images/attach_related_file.PNG)

Now click on the Send button, you will be automatically added in bcc.

![Send](images/click_send_again.PNG)

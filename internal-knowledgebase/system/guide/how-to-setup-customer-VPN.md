# How to set up customer VPN

## Purpose

Establish VPN connectivity between Exasol support environment and customer network.

## Workflow

1. Create a Salesforce case for customer communication.
2. Send ITM VPN form to customer and request completion:
   - English: <https://exasol.atlassian.net/wiki/spaces/IT/pages/911441975/EXASOL+Fortinet+VPNs+EN>
   - German: <https://exasol.atlassian.net/wiki/spaces/IT/pages/911441922/EXASOL+Fortinet+VPNs+Ger>
3. Create Service Desk ticket and attach/forward completed form to ITM.
4. If needed, schedule coordination call with ITM and customer network team.

## Validation

- ITM confirms VPN setup completed.
- Support host can reach required customer endpoints.

# Architecture Overview

This section describes the architecture of an Exasol on-premises installation.

Exasol's architecture is organized into four main areas:

- **Cluster Architecture** — database layer with shared-nothing MPP, storage layer with EXAStorage and BucketFS, network layer with private/public networks, and software components.
- **Redundancy** — how data replication works across nodes using the redundancy attribute on storage volumes.
- **Network** — private and public network infrastructure for an Exasol deployment.
- **Software** — overview of Exasol applications and administration interfaces.
